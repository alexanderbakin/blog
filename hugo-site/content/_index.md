Hi, I'm Alex - a DevOps / Cloud Infrastructure engineer.

This blog is itself a production-grade infrastructure project. Every post is an opportunity to explore real architecture decisions, not just toy examples.

**What you'll find here:**

- **Cloud Architecture** - AWS, serverless, edge computing
- **Infrastructure as Code** - Terraform, Terragrunt, CDK
- **CI/CD** - GitHub Actions, GitLab CI, ArgoCD, GitOps
- **Kubernetes** - EKS, Helm, service mesh
- **Security** - IAM, OIDC, zero-trust patterns
- **Observability** - monitoring, logging, tracing at scale

---

*This blog is built with [Hugo](https://gohugo.io/), deployed via [GitHub Actions](https://github.com/features/actions) with OIDC, and served from [AWS CloudFront](https://aws.amazon.com/cloudfront/) with S3 origin. Infrastructure is managed entirely through Terraform with a PR-driven pipeline.*
